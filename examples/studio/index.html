A guided run of examples/dinner_party.py. The left column runs each step. The panels on the right show what the database did.

loading

1Write the memory

A graph memory stores three things: entities such as people, events and things; edges between entities, for example ; and facts, each attached to the entities it is about. This step deletes the database and writes the whole story, every fact carrying the writer who told it and the day it was told.

2Ask the two-hop question

The question is:

Text search finds only what shares words with the query, and a vector store finds only what sounds like it. Neither follows a chain of facts. The graph arm walks out from the seed entity and returns every fact attached to the entities it reaches. The walk is drawn in the graph panel as it runs.

3The world changes

supersede writes the new fact, closes the old one by setting its valid_to, and records a SUPERSEDES edge between the two versions. Nothing is deleted. Ask again and the answer changes, because recall returns only facts that are current.

4The model proposes a write

The user says: The model calls the remember tool. The server parks the call and waits for a decision before it writes anything. Approve to store the fact with writer glm-5.3-flash, or decline to send the model a refusal and let it finish its answer.

5Time travel

Every row carries two intervals: valid time, when the fact was believed true, and transaction time, when the database knew about it. as_of(t) filters on both, so a read at an earlier instant still returns the belief that was current then, even though that row is closed now. This step needs no model.

6Provenance

provenance(id) walks the SUPERSEDES chain from a memory back to its first version and collects the episodes and writers along the way. After the change that is two versions, two episodes and two writers, which is how an answer is traced back to the message it came from. This step needs no model.

Graph

Circles are entities, squares are facts attached to the entities they are about. Lines between entities are RELATES_TO edges with their kind. A hollow square is a fact that has been superseded. Drag nodes to rearrange.

Recall arms

recall fuses up to three arms with reciprocal rank fusion. The text arm is BM25 over the query words. The graph arm is a two-hop walk from the seed entity, newest fact first. The vector arm is inactive here because this demo stores no embeddings. A blank cell means that arm did not find the row.

Model

GLM 5.3 Flash via OpenRouter, with two tools: recall (runs at once) and remember (waits for a person). The model's reasoning_details are passed back unmodified on the next request. Tool results and reasoning are collapsed; open them to read the raw text.
